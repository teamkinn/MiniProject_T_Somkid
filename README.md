# MiniProject_T_Somkid
MiniProject Teacher.somkid
WebApp คัดแยกขยะอัตโนมัติจากรูปภาพ
พัฒนาด้วย frontend = vue.js, backend = node.js(Express), ใช้ MongoDB เป็นdatabase 
ทำการพัฒนาโมเดล Ai คัดแยกขยะ
การทำงานของ WebApp มีดังนี้
1.คัดแยกประเภทขยะ(รีไซเคิล,ขยะทั่วไป,ขยะย่อยสลาย,ขยะอันตราย) 
2.เลือกรูปภาพที่จะคัดแยกได้หลายรูปพร้อมกัน(1ภาพต่อขยะ1ชิ้น) 
3.สามารถดูผลการวิเคระห์ได้ 
4.ดูประวัติ/ลบการวิเคระห์ได้

มันจะมีไฟล์ Frontend, Backend, API
เริ่มต้นให้รันไฟล์ api.py backend frontend 
api.py = python api.py
backend = node server.js
frontend = npm run dev
